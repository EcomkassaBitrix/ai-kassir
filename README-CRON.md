# Автоматическая очистка логов на VPS

## Установка

На твоём VPS выполни:

```bash
# 1. Скопируй файл на сервер
scp cron-setup.sh user@your-vps:/tmp/

# 2. Подключись к серверу
ssh user@your-vps

# 3. Запусти установку (требуется sudo)
sudo bash /tmp/cron-setup.sh
```

## Что делает

- Создаёт скрипт `/usr/local/bin/cleanup-logs.sh`
- Добавляет cron задачу: **каждые 7 дней в 03:00 ночи**
- Вызывает Cloud Function для очистки логов БД
- Логирует результаты в `/var/log/cleanup-logs.log`

## Управление

```bash
# Посмотреть задачи cron
crontab -l

# Посмотреть логи очистки
sudo tail -f /var/log/cleanup-logs.log

# Тестовый запуск вручную
sudo /usr/local/bin/cleanup-logs.sh

# Удалить задачу cron
crontab -e  # и удали строку с cleanup-logs.sh
```

## Расписание cron

По умолчанию: `0 3 */7 * *` = каждые 7 дней в 03:00

Можешь изменить расписание:
- `0 3 * * 0` — каждое воскресенье в 03:00
- `0 2 1 * *` — 1-го числа каждого месяца в 02:00
- `0 4 */3 * *` — каждые 3 дня в 04:00

Редактировать: `crontab -e`

## Что очищается

Функция удаляет записи старше **7 дней** из таблиц:
- `telegram_previews` (превью чеков в боте)
- `telegram_edit_states` (состояния редактирования)
- `telegram_links` (неактивные ссылки привязки)
